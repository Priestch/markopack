# rs-marko-run

Rsbuild integration packages for `@marko/run`.

## Packages

- `@rs-marko-run/core`: shared route building/codegen/middleware utilities
- `@rs-marko-run/rsbuild`: Rsbuild plugin for `@marko/run`
- `@rs-marko-run/adapter-node`: Node adapter
- `@rs-marko-run/adapter-static`: Static adapter
- `@rs-marko-run/adapter-netlify`: Netlify adapter

## Example

- `examples/rsbuild-basic`: runnable `@marko/run` + Rsbuild setup using the new package
