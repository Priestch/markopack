# markopack

Rspack integration packages for `@marko/run`.

## Packages

- `@markopack/core`: shared route building/codegen/middleware utilities
- `@markopack/compiler`: Marko compiler plugin and loader for rspack
- `@markopack/rspack`: direct rspack integration with `build()` / `dev()` APIs
- `@markopack/adapter-node`: Node adapter
- `@markopack/adapter-static`: Static adapter
- `@markopack/adapter-netlify`: Netlify adapter

## Example

- `examples/rspack-basic`: runnable `@marko/run` + rspack setup
