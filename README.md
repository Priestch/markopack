# rs-marko-run

Rspack integration packages for `@marko/run`.

## Packages

- `@rs-marko-run/core`: shared route building/codegen/middleware utilities
- `@rs-marko-run/marko-rspack`: Marko compiler plugin and loader for rspack
- `@rs-marko-run/rspack`: direct rspack integration with `build()` / `dev()` APIs
- `@rs-marko-run/adapter-node`: Node adapter
- `@rs-marko-run/adapter-static`: Static adapter
- `@rs-marko-run/adapter-netlify`: Netlify adapter

## Example

- `examples/rspack-basic`: runnable `@marko/run` + rspack setup
